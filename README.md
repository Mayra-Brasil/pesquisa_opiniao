# Quantificação de resultado de pesquisa de opinião 📈

Programa feito em **Python** com o objetivo de entrevistar 50 usuários, solicitando seu nome, idade e sua avaliação do atendimento recebido, através da estrutura de repetição **for**.

## Funcionamento ⛓️

Para quantificar as opiniões, antecipadamente tornará elas em uma "variável" de valor "nulo"; após a estrutura de repetição feita, incluir o if, else e elif para enumerar as "variáveis" "EXCELENTE", "BOM" e "RUIM", guardando suas repetições do **for** para a saída posteriormente. Atrelando a enumeração a um valor igual e/ou maior que um, logo, ao contabilizar cada uma delas, apresentaria um valor diferente de zero, informando assim sua quantidade de repetição!
